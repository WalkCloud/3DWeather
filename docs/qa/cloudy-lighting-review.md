# 阴天光照与云层对比

1. 晴天基准：光照与晴天状态一致，暖光、蓝天及阴影作为比较参照。
2. 调整前阴天：地面与晴天过于接近；三团云发白、模糊，内部层次不足。
3. 调整后阴天：直射光显著减弱，地面曝光降低、阴影更柔和；云峰、灰色云底和疏密变化可辨。正背面环绕均有云体积，背面屋顶无遮挡。
